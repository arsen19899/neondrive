# NeonDrive — оболочка для Android-магнитол

Аналог AGAMA Car Launcher: полноценная замена рабочего стола головного устройства,
собранная на Kotlin + Jetpack Compose. Главный экран построен по логике CarPlay,
оформление — неон и киберпанк.

## Музыка

| Источник | Как работает |
|---|---|
| **С устройства** | Сканирование MediaStore по всем томам — внутренняя память, SD, USB. Воспроизведение через ExoPlayer в фоновом `MediaSessionService`. |
| **Радио** | Интернет-потоки (8 пресетов + свои станции), HLS/ICY через ExoPlayer. |
| **Яндекс.Музыка** | Приложение нельзя воспроизвести своим движком, поэтому оболочка работает как полноценный пульт: поднимает приложение, дожидается появления медиасессии, показывает трек с обложкой, переключает треки и ставит лайк. Требуется разрешение «Доступ к уведомлениям». |

**Про лайк.** Приложения реализуют его по-разному, поэтому оболочка пробует два пути:
сначала собственное действие медиасессии (`customActions` с признаком like), затем
стандартный рейтинг сессии (`ACTION_SET_RATING`, сердце или палец вверх). Кнопка
сердца появляется в плеере только если сессия действительно умеет лайкать —
пустых кнопок, которые ничего не делают, не будет.

Эквалайзер — системные эффекты Android: полосы, пресеты, бас, объём, loudness.

## Особые настройки

### 1. Автопроигрывание музыки — вкл/выкл
Музыка стартует сама после включения головного устройства. Настраивается источник
автостарта (устройство / радио / Яндекс.Музыка) и задержка 0–30 с — по умолчанию
задержки нет, музыка включается сразу.

Для Яндекс.Музыки автостарт устроен аккуратно: оболочка поднимает приложение и ждёт,
пока оно создаст медиасессию, и только потом шлёт play. Без этого ожидания команда
уходила бы в пустоту, пока приложение грузится.

### 2. Пауза при уведомлениях с подключённого девайса
Три режима:

* **Нет** — играем дальше;
* **Приглушать** — громкость опускается до заданного % на время уведомления;
* **Да, ставить на паузу** — полная пауза с автоматическим возвратом.

Дополнительно: уровень приглушения (5–90 %), время удержания (0,5–15 с) и фильтр
«только уведомления телефона» — реагировать лишь на то, что пришло по Bluetooth,
а не на всё подряд с самой магнитолы.

### 3. Увеличение громкости при скорости — вкл/выкл
При включении доступны **четыре ступени**: для каждой задаётся порог скорости и
прибавка к базовой громкости в процентах. Заводская схема — 0 / 60 / 90 / 120 км/ч
с прибавками 0 / +6 / +12 / +20 %. Есть пресеты «Тихий город» и «Трасса».
Громкость подтягивается плавно (не более 2 % за такт), а если водитель сам крутит
ручку — новый уровень принимается за базовый.

### 4. Возврат музыки после телефонного вызова
Если автопроигрывание включено, после завершения разговора воспроизведение
включается само (задержка 0–15 с). Состояние вызова определяется по режиму
аудиосистемы, поэтому работает и для Bluetooth hands-free, а не только для
встроенной телефонии.

## Телефон

Телефонная книга берётся из системной базы устройства — на магнитоле она обычно
прилетает с телефона по Bluetooth-профилю PBAP и складывается туда же. Поиск работает
и по имени, и по цифрам номера: на ходу набрать три цифры быстрее, чем целиться в буквы.
Цифры, набранные на клавиатуре номеронабирателя, тоже фильтруют список.

Звонок — в одно касание по строке контакта. Избранные подняты вверх и помечены звездой.

## Оболочка по умолчанию

Назначить себя домашним экраном приложение не может — это всегда осознанный выбор
пользователя. Что делает галочка в настройках: показывает текущее состояние и открывает
нужный системный диалог одним шагом. На Android 10+ это точечный диалог роли HOME,
на старых прошивках — экран «Приложение для главного экрана».

Если диалог не появляется, значит домашний экран уже закреплён за другим приложением —
рядом есть кнопка, открывающая его карточку, где надо нажать «Удалить настройки
по умолчанию».

Отдельный тумблер «Запускать при пробуждении» поднимает оболочку при каждом включении
экрана. Запуск активности из фона на Android 10+ разрешён приложениям, назначенным
домашним экраном, — поэтому настройка работает в паре с предыдущей. Во время
разговора оболочка на передний план не лезет.

## Кнопки руля (резистивные)

Поддержаны оба способа подключения:

1. **KeyEvent** — ядро уже разложило резистивную «лесенку» в клавиши.
   Перехват идёт и в активити, и через `MEDIA_BUTTON`-ресивер, когда лаунчер в фоне.
2. **ADC напрямую** — если ядро отдаёт «сырое» значение в sysfs-ноду
   (`/sys/class/adc_key/value` и подобные). Оболочка опрашивает ноду каждые 60 мс и
   сопоставляет значение с обученной кнопкой по допуску разброса.

**Режим обучения:** «Настройки оболочки → Кнопки руля → Обучить», затем нажать кнопку
на руле. Ловится код клавиши или значение АЦП. Одну кнопку можно назначить дважды —
коротким и долгим нажатием (порог 250–2000 мс).

Доступные действия: плей/пауза, следующий, предыдущий, громче, тише, мьют,
смена источника, принять вызов, сбросить вызов, голосовой помощник, домой,
навигация, все приложения.

## Как получить APK

Нужны Android SDK и **JDK 17** (Android Gradle Plugin 8.x с JDK 11 не соберётся).

### Вариант 1 — Android Studio (проще всего)

1. `File → Open` → папка `NeonDrive`.
2. Studio сама скачает Gradle Wrapper, SDK-компоненты и зависимости.
3. `Build → Build Bundle(s)/APK(s) → Build APK(s)`.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2 — командная строка

```bash
cd NeonDrive
gradle wrapper --gradle-version 8.9   # один раз, если папки gradle/wrapper ещё нет
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### Вариант 3 — сборка в облаке, без установки чего-либо

В проекте лежит `.github/workflows/build-apk.yml`. Залейте папку в репозиторий
GitHub — на вкладке **Actions** запустится сборка, а готовый APK появится в
артефактах (`NeonDrive-apk`), откуда его можно скачать и поставить на магнитолу.
Это самый быстрый путь, если под рукой нет машины с Android SDK.

Release-сборка подписана постоянным ключом из `keystore/neondrive-release.jks`
(лежит в репозитории намеренно — см. комментарий в `app/build.gradle.kts`), тот же
ключ используется что при локальной сборке, что на GitHub Actions. Это важно:
раньше release подписывался автосгенерированным `debug.keystore`, а на Actions
каждый прогон workflow стартует с чистой машины без сохранённого ключа — значит,
каждая сборка подписывалась заново случайным ключом, и Android отказывался
ставить новый APK поверх старого («приложение не установлено» / конфликт
подписи), пока старую версию не удалишь вручную. С постоянным ключом обновления
ставятся поверх старой версии как обычно — не нужно ничего удалять. Свой
keystore нужен, только если публикуете сборку в маркете.

`minSdk 23` — берут почти все ГУ, от Android 6 до 14.

### После установки

1. **Настройки Android → Приложения по умолчанию → Главный экран** → NeonDrive.
2. **Доступ к уведомлениям** → включить NeonDrive
   (нужно для реакций на уведомления и для управления Яндекс.Музыкой).
3. Выдать разрешения: геолокация (спидометр), музыка, телефон, Bluetooth.

Пункты 1–3 продублированы в самой оболочке: «Настройки оболочки → Система».

## Карта на рабочем столе

Два режима, выбираются в «Настройки оболочки → Навигация».

| Режим | Как выглядит | Что нужно |
|---|---|---|
| **Своя карта** | Оболочка рисует интерактивную карту OpenStreetMap прямо в панели и сама ведёт по маршруту: поиск, манёвры, голос. Сторонний навигатор не нужен | ничего |
| **Поверх карты** | Чужой навигатор занимает весь экран, приборы и плеер оболочки висят поверх него по краям | разрешение «Поверх других приложений» |

Заводской режим — **«Своя карта»**. Показать *чужое* приложение на части экрана
Android не разрешает: split-screen домашнему экрану недоступен, запуск на
виртуальный дисплей с Android 10 запрещён для чужих активностей, а freeform
требует прошивки, которой на большинстве ГУ нет. Своя карта живёт внутри окна
оболочки, поэтому ограничения оконного менеджера на неё не действуют вообще.

> Режим «Во фрейме» (плавающее окно навигатора по границам панели) удалён в
> версии 1.4 вместе со всей обвязкой. Он требовал freeform-режима прошивки,
> который приложение включить не может, — то есть у большинства просто не
> работал, а сложности добавлял всем.

**Доля экрана под навигацию** настраивается ползунком в «Настройки оболочки →
Навигация» (30–80 %, пресеты «треть / половина / две трети»). Заводское значение —
**50 %**. На рабочем столе это ширина панели карты, в режиме «Поверх карты» —
столько же остаётся свободным между панелями оболочки. При доле от двух третей
плеер автоматически переключается на вертикальную раскладку: обложка во всю
ширину, название в две строки, крупный транспорт — иначе в узкой колонке он
становится нечитаемым.

**Офлайн.** Кэш тайлов и офлайн-архивы лежат в
`Android/data/com.neondrive.launcher/files/osmdroid/`. Папка видна с компьютера по
USB: если скинуть туда офлайн-карту региона (`.mbtiles`, `.sqlite`, `.zip`), карта
будет работать вообще без интернета.

## Яндекс.Навигатор: что реально возможно

Установленный Навигатор и подписка Плюс в нём относятся к аккаунту пользователя
**внутри того приложения**. Наружу он не отдаёт ничего: публичного API нет, только
односторонние URL-схемы. Команду «построй маршрут туда-то» принять можно, а спросить
«какая у маршрута геометрия и какой следующий манёвр» — нельзя. Поэтому отрисовать
чужое ведение в своей карте технически невозможно: данных просто неоткуда взять.

Карты Яндекса своим рендерером тоже не нарисовать — это MapKit SDK, он требует
ключ разработчика. **Оболочка сознательно на него не завязана:** карта строится на
OpenStreetMap через osmdroid, чтобы работать у любого сразу после установки, без
регистраций, ключей и лицензионных лимитов.

Что оболочка делает вместо этого, и ключ для этого не нужен:

**0. Собственная навигация — сторонний навигатор не нужен.** В режиме «Своя карта»
оболочка ведёт сама, от поиска точки до голоса на повороте:

* **поиск** — адреса и названия мест по мере набора ([Photon](https://photon.komoot.io/),
  запасной — Nominatim), выдача смещена к текущей позиции: «лен» рядом с домом даст
  соседнюю Ленина, а не Ленинград;
* **категории рядом** — заправки, зарядки, поесть, магазины, парковка, ночлег, отдых,
  аптека, банкомат, автосервис, туалет. Одно касание вместо набора текста на ходу
  (Overpass API, радиус расширяется автоматически: 5 → 20 → 60 км);
* **маршрут** — открытый роутер [OSRM](https://project-osrm.org/) с манёврами;
* **ведение** — карточка следующего манёвра со стрелкой, расстоянием и «затем…»,
  остаток пути и время, автоматическое перестроение при сходе с маршрута;
* **голос** — системный TextToSpeech, фразы на трёх рубежах перед манёвром, рубежи
  считаются от скорости. Выключается тумблером в настройках.

**Чего в этом стеке нет и взять негде: пробок, камер и предупреждений.** Маршрут
строится по графу дорог, а не по обстановке, время в пути — оценка по разрешённым
скоростям. Когда пробки важнее, кнопка справа внизу открывает установленный
навигатор на весь экран, а «Домой» в остальных режимах карты по-прежнему отдаёт
точку ему.

Данные OSM в России полны на адреса и заметные объекты, но свежее кафе или
маленький магазин может отсутствовать. Все сервисы — публичные, живущие на
пожертвованиях: поиск шлёт запрос после паузы в наборе, а не на каждую букву. При
массовой раздаче сборки поднимите свой инстанс OSRM и поменяйте `OSRM_BASE` в
`nav/RouteHub.kt`.

**1. URL-схемы Навигатора** ([документация Яндекса](https://yandex.com/dev/yandex-apps-launch/navigator)):

* `yandexnavi://build_route_on_map?lat_from=&lon_from=&lat_to=&lon_to=` — кнопка «Домой»
  строит маршрут от текущей позиции GPS до сохранённой точки;
* `yandexnavi://show_point_on_map?lat=&lon=&zoom=&desc=` — кнопка «Я здесь».

Точка «Дом» запоминается одной кнопкой в настройках: «Навигатор → Запомнить здесь»
берёт текущие координаты GPS, никакого выбора на карте не требуется.

**2. Полноэкранный запуск с панелями поверх** — режим «Поверх карты», когда нужны
пробки Яндекса, а не свой маршрут.

**3. Нарисованный HUD** (`MapCanvas` в `ui/home/MapPanel.kt`) — стилизованная
псевдокарта с курсом и высотой по данным GPS. Остался как заполнитель для режима
«Поверх карты»: пока навигатор не поднят, панель не должна выглядеть пустой.
В заводском режиме «Своя карта» вместо него настоящая карта.

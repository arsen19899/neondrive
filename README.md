# NeonDrive — оболочка для Android-магнитол

Аналог AGAMA Car Launcher: полноценная замена рабочего стола головного устройства,
собранная на Kotlin + Jetpack Compose. Главный экран построен по логике CarPlay,
оформление — неон и киберпанк.

│  радио       │                                │  ▦   │

* **Колонка 25 %** — сверху GPS-спидометр с неоновой дугой, снизу плеер.
* **Карта** — панель Яндекс.Навигатора на оставшиеся ~2/3.
* **Вертикальный док** — часы и дата, ниже шесть плиток:
  телефон · навигация · эквалайзер · настройки Android · все приложения · настройки оболочки.
* Сторона дока переключается в настройках (левый / правый руль).

## Музыка

| Источник | Как работает |
|---|---|
| **С устройства** | Сканирование MediaStore по всем томам — внутренняя память, SD, USB. Воспроизведение через ExoPlayer в фоновом `MediaSessionService`. |
| **Радио** | Интернет-потоки (8 пресетов + свои станции), HLS/ICY через ExoPlayer. |
| **Яндекс.Музыка** | Приложение нельзя воспроизвести своим движком, поэтому оболочка работает как пульт: читает `MediaSession` Яндекс.Музыки и шлёт транспортные команды. Требуется разрешение «Доступ к уведомлениям». |

Эквалайзер — системные эффекты Android: полосы, пресеты, бас, объём, loudness.

## Особые настройки

### 1. Автопроигрывание музыки — вкл/выкл
Музыка стартует сама после включения головного устройства. Настраивается источник
автостарта (устройство / радио / Яндекс.Музыка) и задержка 0–30 с, чтобы система
успела подняться.

### 2. Пауза при уведомлениях с подключённого девайса
Три режима:

* **Нет** — играем дальше;
* **Приглушать** — громкость опускается до заданного % на время уведомления;
* **Да, ставить на паузу** — полная пауза с автоматическим возвратом.

Дополнительно: уровень приглушения (5–90 %), время удержания (0,5–15 с) и фильтр
«только уведомления телефона» — реагировать лишь на то, что пришло по Bluetooth,
а не на всё подряд с самой магнитолы.

### 3. Увеличение громкости при скорости — вкл/выкл
При включении доступны **четыре ступени**: для каждой задаётся порог скорости и
прибавка к базовой громкости в процентах. Заводская схема — 0 / 60 / 90 / 120 км/ч
с прибавками 0 / +6 / +12 / +20 %. Есть пресеты «Тихий город» и «Трасса».
Громкость подтягивается плавно (не более 2 % за такт), а если водитель сам крутит
ручку — новый уровень принимается за базовый.

### 4. Возврат музыки после телефонного вызова
Если автопроигрывание включено, после завершения разговора воспроизведение
включается само (задержка 0–15 с). Состояние вызова определяется по режиму
аудиосистемы, поэтому работает и для Bluetooth hands-free, а не только для
встроенной телефонии.

## Кнопки руля (резистивные)

Поддержаны оба способа подключения:

1. **KeyEvent** — ядро уже разложило резистивную «лесенку» в клавиши.
   Перехват идёт и в активити, и через `MEDIA_BUTTON`-ресивер, когда лаунчер в фоне.
2. **ADC напрямую** — если ядро отдаёт «сырое» значение в sysfs-ноду
   (`/sys/class/adc_key/value` и подобные). Оболочка опрашивает ноду каждые 60 мс и
   сопоставляет значение с обученной кнопкой по допуску разброса.

**Режим обучения:** «Настройки оболочки → Кнопки руля → Обучить», затем нажать кнопку
на руле. Ловится код клавиши или значение АЦП. Одну кнопку можно назначить дважды —
коротким и долгим нажатием (порог 250–2000 мс).

Доступные действия: плей/пауза, следующий, предыдущий, громче, тише, мьют,
смена источника, принять вызов, сбросить вызов, голосовой помощник, домой,
навигация, все приложения.

## Как получить APK

Нужны Android SDK и **JDK 17** (Android Gradle Plugin 8.x с JDK 11 не соберётся).

### Вариант 1 — Android Studio (проще всего)

1. `File → Open` → папка `NeonDrive`.
2. Studio сама скачает Gradle Wrapper, SDK-компоненты и зависимости.
3. `Build → Build Bundle(s)/APK(s) → Build APK(s)`.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2 — командная строка

```bash
cd NeonDrive
gradle wrapper --gradle-version 8.9   # один раз, если папки gradle/wrapper ещё нет
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### Вариант 3 — сборка в облаке, без установки чего-либо

В проекте лежит `.github/workflows/build-apk.yml`. Залейте папку в репозиторий
GitHub — на вкладке **Actions** запустится сборка, а готовый APK появится в
артефактах (`NeonDrive-apk`), откуда его можно скачать и поставить на магнитолу.
Это самый быстрый путь, если под рукой нет машины с Android SDK.

Release-сборка подписана отладочным ключом, поэтому `app-release.apk` тоже
ставится на устройство сразу — свой keystore нужен только для публикации в маркете.

`minSdk 23` — берут почти все ГУ, от Android 6 до 14.

### После установки

1. **Настройки Android → Приложения по умолчанию → Главный экран** → NeonDrive.
2. **Доступ к уведомлениям** → включить NeonDrive
   (нужно для реакций на уведомления и для управления Яндекс.Музыкой).
3. Выдать разрешения: геолокация (спидометр), музыка, телефон, Bluetooth.

Пункты 1–3 продублированы в самой оболочке: «Настройки оболочки → Система».

## Яндекс.Навигатор: что реально возможно

Установленный Навигатор и подписка Плюс в нём относятся к аккаунту пользователя
**внутри того приложения**. Стороннему лаунчеру они не дают права рисовать карту
Яндекса у себя в окне: отрисовка — это MapKit / NaviKit SDK, а он требует
собственный ключ разработчика ([MapKit SDK](https://yandex.com/maps-api/products/mapkit),
[NaviKit SDK](https://yandex.com/maps-api/products/navikit)). Более того, у
бесплатного тарифа MapKit прямо запрещена навигация по маршруту, а NaviKit выдаётся
только по заявке. Так что «без ключа за счёт подписки» — увы, не работает.

Что оболочка использует вместо этого, и ключ для этого не нужен:

**1. URL-схемы Навигатора** ([документация Яндекса](https://yandex.com/dev/yandex-apps-launch/navigator)):

* `yandexnavi://build_route_on_map?lat_from=&lon_from=&lat_to=&lon_to=` — кнопка «Домой»
  строит маршрут от текущей позиции GPS до сохранённой точки;
* `yandexnavi://show_point_on_map?lat=&lon=&zoom=&desc=` — кнопка «Я здесь».

Точка «Дом» запоминается одной кнопкой в настройках: «Навигатор → Запомнить здесь»
берёт текущие координаты GPS, никакого выбора на карте не требуется.

**2. Запуск Навигатора в окне поверх панели карты.** Настройка «Открывать в окне»
поднимает приложение в плавающем окне ровно по границам панели — визуально это и есть
карта внутри рабочего стола. Нужен freeform-режим прошивки; на большинстве китайских
ГУ он есть, но выключен, включается один раз:

```bash
adb shell settings put global enable_freeform_support 1
adb shell settings put global force_resizable_activities 1
```

Если прошивка команду не приняла, оболочка молча откроет навигатор на весь экран.

**3. Свой HUD.** Пока навигатор не открыт, панель рисует стилизованную карту с
маршрутом, курсом и высотой по данным GPS — чтобы рабочий стол не выглядел пустым.

Если ключ MapKit всё же появится — замените `MapCanvas` в `ui/home/MapPanel.kt` на
`MapView`, остальная разметка не изменится.
